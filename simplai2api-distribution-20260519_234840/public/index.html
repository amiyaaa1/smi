SimplAI2API 管理台

OpenAI 格式中转 + 多账号轮询 + 自动补号

服务信息

POST /v1/chat/completions
仅使用: messages / max_tokens(max_completion_tokens) / temperature / stream
轮询策略: 每次优先使用“最久未使用”的可用账号

统一配置

自动补号 / 积分阈值 / 最大池

账号列表

模板账号: -
账号 邮箱 用户/项目 剩余积分 使用/刷新 状态 操作

新增 / 编辑账号

OpenAI 调用示例

curl http://127.0.0.1:8031/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "anything",
    "messages": [
      {"role": "system", "content": "Be concise."},
      {"role": "user", "content": "Reply with OK only."}
    ],
    "temperature": 0.2,
    "max_tokens": 32,
    "stream": false
  }'
